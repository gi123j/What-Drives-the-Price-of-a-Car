## 📌 Project Overview
This repository contains an end-to-end data science project investigating the primary drivers of used car prices. Following the **CRISP-DM (Cross-Industry Standard Process for Data Mining)** framework, this analysis applies data cleaning, exploratory data analysis (EDA), feature engineering, and penalized multiple regression techniques to deliver actionable pricing and inventory acquisition strategies for used car dealerships.
